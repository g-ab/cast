# Cast

Cast turns a quick sketch of into paper patterns you can print, cut out and use to build it from clay slabs.

You draw the object in three flat views (front, side, top), straighten the sketch into shapes, and Cast works out every slab you need: one flat template for each face. It lays the templates out on A4 or US Letter pages at 1:1, enlarged to make up for the clay shrinking as it dries and fires. Then you download them as a PDF.

It's a single HTML page with no build step and no account. Your drawing stays in your browser, and you save it as a file when you want to keep it.

## How it works

**Home**
- Start a new drawing, open a saved one, or try the example (a stool).
- Drawings you've opened or saved recently are listed here. This list is kept in your browser only.

**Drawing**
- Front, Right side and Top views in third-angle layout, plus a live 3D preview you can turn.
- Sketch with the **Pencil**, then press **Clean** to straighten the strokes into shapes with snapped corners.
- **Select** to move and resize. Double-click a shape to edit its joints, round its corners or add new joints.
- **Measure** to type an exact size or edge length.
- **Split** to draw a line across a piece where a slab should break.
- **Box** adds a 10 cm cube. **Eraser** removes strokes or pieces.
- Select two or more pieces to **Cut** (the smaller ones become holes) or **Merge** them into one shape.
- Shapes snap to the grid and to each other's edges. Hold Alt to place freely.

**Patterns**
- Each piece is broken into flat slabs and placed on pages, turned to fit as tightly as possible.
- Drag templates around and between pages. Add pages, or press **Arrange** to pack everything again.
- Turn a template by dragging the round handle above it. It snaps to every 45°; hold Alt to turn freely. You can also press R (90°), Shift+R (−90°), or type any angle.
- Flip templates left to right or top to bottom.
- Pieces too big for one sheet are split across pages that you tape together.
- **Download pattern** saves a 1:1 PDF.

## Settings

The unit tag next to the drawing name (mm ▾) opens:

- **File:** Open, Save, Download pattern.
- **Canvas:** mm or cm, the depth given to new pieces, snap grid (1, 5 or 10 mm), and snapping on or off.
- **Print:** paper size, **Shape grow** (how much bigger templates are printed to allow for shrinkage, 15% by default), and line weight (0.25–2 pt).

## Saving

- **Save** (⌘S / Ctrl+S) downloads `<name>.json`. It holds the drawing, the page layout and the print settings.
- **Open** loads that file back in.
- Click the name at the top to rename the drawing. A blue dot next to it means there are changes you haven't saved to a file.
- Your current work is also kept in the browser, so a reload won't lose it. That copy only lives in that browser, though, so save a file to keep a drawing.

| P · C · V · M · S · B · E | Pencil, Clean, Select, Measure, Split, Box, Eraser |
| F | Fit everything in view |

| R / Shift+R | Turn the selected template 90° / −90° (Patterns) |
| ⌘Z / ⇧⌘Z | Undo / redo, in both tabs (Ctrl on Windows) |
| ⌘S | Save |
| Space + drag, or right-drag | Pan |
| Scroll | Zoom |

## Pattern rules

- Wall thickness isn't modelled. Each wall becomes one slab, and a hole only marks an open face.
- Thin pieces (15 mm or less, or no more than a quarter of their next side) print as a single flat outline.
- Cut lines print solid and fold lines dashed, at the line weight you choose.

## Running it

Open `index.html` through any static web server, for example:

```sh
python3 -m http.server
```

Then go to http://localhost:8000. It needs an internet connection for three.js (the 3D preview), jsPDF (the PDF) and Google Fonts. The `.nojekyll` file lets it run on GitHub Pages as is.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole app: markup, styles and script |
| `stylist-theme.css` | The theme generated by [Stylist](https://github.com/g-ab/stylist). Don't edit it by hand |
| `app-tokens.css` | Cast's own tokens: grid, axis, pencil, fill, cut and clay colours |
| `stylist-icons.css` | Icon sizing and stroke |
| `stylist.json`, `components.json` | The Stylist recipe and component spec this look came from |
| `brand/` | Logo (light and dark), mark, favicon and their CSS |
| `CLAUDE.md` | How to apply a new Stylist setup to Cast |

Styles load in this order: theme → app tokens → icons → brand. Only `--clay` and the `.clay` classes refer to the clay material colour.

## Look and feel

Colours, typefaces (Schibsted Grotesk and IBM Plex Mono), corners, shadows, spacing, control sizes, focus rings and motion all come from Stylist tokens, in light and dark mode. Animations follow the system's reduced-motion setting: fades stay, movement is dropped.

To restyle Cast, make a new setup in Stylist and follow `CLAUDE.md`.
