# Cast brand files

Generated by Stylist. Every file is trimmed to its drawing and has a viewBox; marks and the favicon are square. So set a height and keep width auto: it fits avatars, icon buttons, headers and tabs as is.

- Favicon: `<link rel="icon" type="image/svg+xml" href="/brand/favicon.svg">`.
- Light/dark: import `brand.css` once, then put both files side by side with the classes `brand-light` and `brand-dark`.
